# 图片制作参考

## 默认白板风

使用已认可的白板样张时，将其作为画风参考。没有样张时，用以下约束描述风格：

- 3:4 竖版、完全不透明的纯白背景；黑色马克笔笔触，少量低饱和雾蓝下划线或箭头。
- 手写中文字清楚易认；主标题最多两行是优先方案，不能以压缩字体换取硬塞。
- 图标使用简单手绘线条；每页一幅核心示意，保留足够边距和组间留白。
- 不添加口号、细碎注释、装饰英文、过多涂鸦；不使用真实白板边框、场景照片、三维质感或大片渐变。
- 新请求指定其他风格时替换这些偏好，保留可读性和信息层级要求。

## 提示词结构

1. 任务类型：新图、改图或仅风格转换。
2. 参考图作用：风格参考与实际编辑对象分别说明。
3. 系列规范：比例、颜色、字体、边距、品牌与页码位置。
4. 本页唯一核心信息。
5. 需要逐字呈现的文字，含标题、标签、示例标注和页码。
6. 一幅主示意的关系与阅读顺序。
7. 保持项与排除项：内容不变或指定修改；无额外口号；背景不透明。

图片里的文字越少，越容易保持可读性。不要把完整正文交给生成器自行压缩。需要删减时先修改分页文案。

## 视觉检查

- 缩小看：是否第一眼看见本页主题？图标是否压过信息？
- 正常尺寸看：正文是否无需放大也能阅读？边距和留白是否足够？
- 核对文字：中文、产品名、专业术语、URL、页码有没有错漏？
- 核对事实：有没有擅自增加成绩、数字、人物背景或功能？
- 核对系列：字体、色调和线条语言是否接近已认可样张？
- 核对文件：是否出现透明背景、黑底、裁切，最终目录是否包含全部修正版，页数和顺序是否正确？

技术失败可以做有限重试；成功页先保存。持续失败时说明具体缺页并交付已完成内容，避免无止境生成。质量修改优先针对用户指出的问题或检查发现的具体缺陷。
