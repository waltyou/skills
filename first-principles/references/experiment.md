# E: Experiment

Design the smallest practical test of each selected candidate's critical assumption. Specify the action, resources, observable result, rejection and continuation criteria, and learning from either outcome. Respect the user's time, cost, effort, and social-risk limits.

Distinguish hypothesis failure, execution failure, and inconclusive evidence. Mark unsupported thresholds as provisional and identify the needed baseline. Passing a small test justifies further investigation, not full validation.

Prioritize the first test by information value and cost. Identify what to revisit if all candidates fail. Deliver test plans; execute only within the user's authorization, and report results only when observed.
